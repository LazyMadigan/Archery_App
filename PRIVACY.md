# Privacy

**Short version: nothing leaves your phone.**

- 3D Fun Round has no accounts, no sign-in, no server and no analytics.
- Everything you enter (names, scores, courses, traced rings) is stored only in your phone's browser storage (`localStorage`). It never gets sent anywhere.
- The app is hosted as plain files on GitHub Pages. When you open it, GitHub's servers serve those files — that's an ordinary website visit, the same as any page you load. We don't receive anything from it. The display font is loaded from Google Fonts in the same way.
- Sharing is always your choice: "Save image" / "Share" on a round summary makes a picture that you decide what to do with. "Copy JSON" in the tracing tool puts text on your clipboard; it only goes to us if you paste it somewhere.
- Clearing your browser data, or using Settings → Clear all, deletes everything. There is no copy anywhere else, so use Settings → Export backup if you want one.
- No ads, no tracking, no selling anything. Nobody involved is paid.

If you ever find this isn't true of the code, open an issue — the source is all here.
